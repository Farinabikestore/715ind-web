# 715IND web

Sitio de marca 715IND: multi idioma (es, en, pt, de, fr, it), armador de ruedas, formulario para distribuidores y panel de edición (Sveltia CMS en `/admin/`).

Stack: Astro (sitio estático) + Cloudflare Pages (hosting y funciones) + Turnstile (antibots) + Resend (correo).

**Guía paso a paso de publicación y uso: [GUIA.md](GUIA.md)**

```bash
npm install
npm run dev     # http://localhost:4321/es/
npm run build   # compila a dist/
```
